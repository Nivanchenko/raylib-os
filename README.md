## Raylib-os

Обертка над https://github.com/raylib-cs/raylib-cs, которая в свою очередь обертка над https://github.com/raysan5/raylib.

Изначально библиотека для создание графических приложений (в т.ч. и игр) с 2D, 3D, графикой, шейдерами и тд. Описание родительской библиотеки: https://www.raylib.com

Целью является предоставить все возможности библиотеки в языке OneScript.

В начальной стадии экпиремента. 

## Разработка

Из корня репозитория соберите библиотеку (.NET SDK с поддержкой net6.0):

```bash
dotnet build src/raylibos/raylibos.csproj
```

При установленном `oscript` можно проверить синтаксис всех демо без запуска окна:

```bash
for script in src/test*.os; do oscript -check "$script" || exit 1; done
oscript -check examples/physics/app.os
```

Для визуальной проверки запустите, например, `oscript src/test.os` после сборки. Демо с текстурами и моделями запускайте из корня репозитория: пути к `resources/` зависят от рабочего каталога. Скрипты ищут отладочную DLL по пути относительно самого `.os`-файла. Это интерактивные примеры: они работают до закрытия окна, а проверка синтаксиса не проверяет вызовы библиотеки.

Для добавления методов и проверки изменений см. [AGENTS.md](AGENTS.md); список идей по расширению API — в [tasks/README.md](tasks/README.md). Ручные проверки интерактивных сценариев — в [tasks/manual-checklist.md](tasks/manual-checklist.md).

Ввод данных
- КлавишаНажата(keyCode) - клавиша удерживается (`IsKeyDown`); историческое имя сохранено
- КлавишаНажатаОдин(keyCode) / КлавишаПовторноНажата(keyCode) / КлавишаОтпущена(keyCode) / КлавишаНеНажата(keyCode) - события нажатия, повторения, отпускания и отсутствие нажатия
- ПолучитьНажатуюКлавишу() / ПолучитьВведенныйСимвол() - взять код клавиши / код Unicode-символа из очереди (0, если очередь пуста)
- УстановитьКлавишуВыхода(keyCode) - поменять клавишу закрытия окна (по умолчанию ESC)
- ПозицияМыши() - позиция курсора мыши
- КнопкаМышиНажата(button) / КнопкаМышиЗажата(button) / КнопкаМышиОтпущена(button) / КнопкаМышиНеНажата(button) - события и состояние кнопки мыши
- МышьX() / МышьY() / СмещениеМыши() / КолесоМышиВектор() - координаты, движение и колёсико (два последних возвращают Vector2)
- УстановитьПозициюМыши(x, y) / УстановитьСмещениеМыши(offsetX, offsetY) / УстановитьМасштабМыши(scaleX, scaleY) / УстановитьКурсорМыши(cursor) - настройка координат и формы указателя
- КурсорСкрыт() - проверка видимости курсора
- ПоказатьКурсор() / СкрытьКурсор() - управление видимостью курсора
- ВключитьКурсор() / ОтключитьКурсор() - разблокировать / захватить курсор (не путать с видимостью)
- КурсорНаЭкране() - находится ли курсор в области окна

```bsl

КонецЕсли;
Если Рейлиб.КнопкаМышиОтпущена(0) Тогда // MOUSE_BUTTON_LEFT

КонецЕсли;
```

Перетаскивание файлов в окно
- ФайлПеретащен() / IsFileDropped - есть ли новые файлы, перетащенные в окно; проверять каждый кадр после `ИнициализацияОкна()`
- ПолучитьПеретащенныеФайлы() / GetDroppedFiles - возвращает `Массив` строк-путей (пустой, если файлов нет); нативный список освобождается внутри метода, полученные строки остаются доступны

```bsl
// В игровом цикле:
Если Рейлиб.ФайлПеретащен() Тогда
    Для Каждого Путь Из Рейлиб.ПолучитьПеретащенныеФайлы() Цикл
        Сообщить("Перетащен: " + Путь);
    КонецЦикла;
КонецЕсли;
```
Для ручной проверки запустите `oscript src/testDropFiles.os` и перетащите файл в окно до автоматического закрытия через 10 секунд.

- ЗагрузитьЗвук(fileName) / LoadSound - загрузить короткий звуковой эффект из файла после инициализации устройства; возвращает Sound

- ВоспроизвестиЗвук(sound) / PlaySound - начать проигрывание

Шейдеры

- ПозицияПараметраШейдера(shader, name) / ПозицияАтрибутаШейдера(shader, name) - расположение uniform/атрибута (`-1`, если не найден)

- УстановитьЗначениеШейдераVector2(shader, location, value) / УстановитьЗначениеШейдераVector3(shader, location, value) - векторные uniform
- УстановитьМассивШейдераFloat(shader, location, values) - массив чисел OneScript для uniform `float[]`

Коллизии 3D (не требуют создания окна)


Примечания
- Текстуры и модели должны загружаться ПОСЛЕ инициализации окна (требуется OpenGL контекст)
- Всегда выгружайте текстуры (`ВыгрузитьТекстуру`) и модели (`ВыгрузитьМодель`) после использования
- Image (сгенерированные или загруженные изображения) хранятся в CPU RAM, Texture2D — в GPU VRAM
- После загрузки Texture2D из Image, изображение можно выгрузить для экономии памяти
- Для работы с unsafe кодом (установка текстур на модели) включен `<AllowUnsafeBlocks>true</AllowUnsafeBlocks>`
