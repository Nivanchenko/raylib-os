## Raylib-os

Обертка над https://github.com/raylib-cs/raylib-cs, которая в свою очередь обертка над https://github.com/raysan5/raylib.

Изначально библиотека для создание графических приложений (в т.ч. и игр) с 2D, 3D, графикой, шейдерами и тд. Описание родительской библиотеки: https://www.raylib.com

Целью является предоставить все возможности библиотеки в языке OneScript.

В начальной стадии экпиремента. 

Основы рисования
# Подключение библиотеки
```bsl
КаталогКомпоненты = ОбъединитьПути(ТекущийСценарий().Каталог, "raylibos/bin/Debug/net6.0/raylibos.dll");
ПодключитьВнешнююКомпоненту(КаталогКомпоненты);
Рейлиб = Новый Рейлиб;
```
# Инициализация окна
```bsl
Рейлиб.ИнициализацияОкна("Мое приложение", 800, 600);
```
# Цвета и векторы
```bsl
Белый = Рейлиб.НовыйЦвет(255, 255, 255, 255);
Красный = Рейлиб.НовыйЦвет(255, 0, 0, 255);
Точка = Рейлиб.НовыйВектор(100, 100);
```
# Основной игровой цикл
```bsl
Пока Не Рейлиб.ОкноДолжноЗакрыться() Цикл
    Рейлиб.НачатьОтрисовку();
    Рейлиб.ОчиститьФон(Белый);
    Рейлиб.НарисоватьКруг(Точка.ВекторX(), Точка.ВекторY(), 30, Красный);
    Рейлиб.ЗакончитьОтрисовку();
КонецЦикла;
Рейлиб.ЗакрытьОкно();
```
Ввод с клавиатуры и мыши

2D Камера
# Создание камеры
```bsl
Цель = Рейлиб.НовыйВектор(400, 300);
Смещение = Рейлиб.НовыйВектор(400, 300);
Камера = Рейлиб.НоваяКамера2D(Цель, Смещение, 0, 1);
```
# Использование камеры
```bsl
Рейлиб.НачатьРежим2Д(Камера);
    // Рисование объектов
Рейлиб.ЗакончитьРежим2Д();
```
Доступные методы

Основные функции
- НовыйЦвет(r, g, b, a) - создание цвета
- НовыйВектор(x, y) - создание вектора 2D
- ВекторX(vector) / ВекторY(vector) - получение координат вектора
- ИнициализацияОкна(title, width, height) - создание окна
- ОкноДолжноЗакрыться() - проверка закрытия окна
- НачатьОтрисовку() / ЗакончитьОтрисовку() - начало/конец отрисовки
- ОчиститьФон(color) - очистка фона

Рисование примитивов
- НарисоватьКруг(centerX, centerY, radius, color)
- НарисоватьЭллипс(centerX, centerY, radiusH, radiusV, color)
- НарисоватьПрямоугольник(posX, posY, width, height, color)
- НарисоватьТреугольник(v1, v2, v3, color)
- НарисоватьЛинию(startX, startY, endX, endY, color)
- НарисоватьПолигон(center, sides, radius, rotation, color)

Ввод данных
- КлавишаНажата(keyCode) - проверка нажатия клавиши
- ПозицияМыши() - позиция курсора мыши
- КнопкаМышиНажата(button) - проверка нажатия кнопки мыши
- КурсорСкрыт() - проверка видимости курсора
- ПоказатьКурсор() / СкрытьКурсор() - управление видимостью курсора

2D Камера
- НоваяКамера2D(target, offset, rotation, zoom) - создание камеры
- НачатьРежим2D(camera) / ЗакончитьРежим2D() - режим отрисовки с камерой
- Камера2DЦель(camera) / Камера2DСмещение(camera) / Камера2DВращение(camera) / Камера2DЗум(camera) - получение параметров камеры
- ОбновитьКамеру2D(camera, target, offset, rotation, zoom) - обновление параметров камеры
- ПозицияКолесаМыши() - позиция колеса мыши

3D Графика
- НовыйВектор3(x, y, z) - создание вектора 3D
- НоваяКамера3D(position, target, up, fovy, projection) - создание 3D камеры
- НачатьРежим3D(camera) / ЗакончитьРежим3D() - режим 3D отрисовки
- НарисоватьКуб(position, width, height, length, color) - рисование куба
- НарисоватьКубЛиния(position, width, height, length, color) - рисование каркаса куба

Дополнительные функции
- Случайное(min, max) - генерация случайного числа
- УстановитьЧастотуКадров(fps) - установка частоты кадров
- НарисоватьТекст(text, posX, posY, fontSize, color) - рисование текста
