# Конечная voxel-песочница на Raylib-os

Небольшое интерактивное демо с видом от первого лица: конечный блочный мир, полёт, выбор блоков, установка и удаление, процедурные материалы и направленный свет. Мир и ввод реализованы на OneScript, кубы рисуются через текущий API `Рейлиб`, детали поверхностей — шейдером GLSL 330.

## Требования и запуск

- .NET SDK, способный собирать целевой `net6.0` проект.
- OneScript с командой `oscript` в `PATH`.
- Графическое окружение с поддержкой OpenGL 3.3 / GLSL 330.
- Запускать команды из корня репозитория: пути к `resources/shaders/minecraft/` считаются от текущего каталога.

Проект компонента объявляет NuGet-зависимости OneScript `2.0.0-rc.8` и Raylib-cs `6.0.0`; `dotnet build` восстанавливает их согласно `src/raylibos/raylibos.csproj`.

Соберите компонент и запустите демо:

```bash
dotnet build src/raylibos/raylibos.csproj
oscript examples/minecraft/app.os
```

Сборка по умолчанию создаёт `src/raylibos/bin/Debug/net6.0/raylibos.dll`; приложение подключает эту DLL относительно своего `.os`-файла.

## Управление

| Ввод | Действие |
|---|---|
| Мышь | Поворот камеры, когда курсор захвачен |
| W / S | Вперёд / назад по горизонтали |
| A / D | Влево / вправо |
| Пробел / левый Ctrl | Вверх / вниз |
| 1 / 2 / 3 | Выбрать землю (`DIRT`), воду (`WATER`) или древесину (`WOOD`) |
| ЛКМ | Удалить блок под прицелом одним нажатием |
| ПКМ | Поставить выбранный блок рядом с целью одним нажатием |
| Tab | Захватить или освободить курсор |
| Esc / кнопка закрытия окна | Завершить демо |

После потери фокуса курсор освобождается; при возврате в окно управление нужно включить клавишей Tab. При свободном курсоре полёт и редактирование выключены. Скорость полёта — 4 единицы в секунду; `dt` перемещения ограничен 0.05 секунды на кадр, диагональный ввод нормализуется.

Окно открывается размером 960×540 и допускает изменение размера.

## Мир и ограничения

- Мир — одна сетка 16×16×8 с основанием, холмом, прудом и двумя условными деревьями. Она восстанавливается при каждом запуске; сохранения нет.
- ID блоков: 0 — воздух, 1 — земля, 2 — вода, 3 — древесина. Луч выбирает ближайший блок в пределах 5 единиц. Установка разрешена только в свободную клетку внутри мира и не вплотную к камере.
- Это свободный полёт (`noclip`): нет гравитации, столкновений, прыжка и плавания. Камера может пролетать через блоки; если она находится внутри занятой клетки, выбор и редактирование временно отключаются.
- Вода непрозрачная и неподвижная: анимируется только рисунок/яркость поверхности, не геометрия. Блоки не растекаются и не создают отражений всей сцены.
- Нет инвентаря, ограничений количества блоков, теней, чанков или генерации бесконечного мира.
- Целевой лимит окна — 60 FPS, но фактическая скорость зависит от GPU, драйвера, размера render buffer и разрешения.

## Измерения

Замер `testPerformance.os`: для каждого профиля 5 секунд прогрева и 30 секунд сбора кадров; FPS не ограничивается. Результаты относятся к одной среде и не являются обещанием производительности на другом устройстве.

Среда замера: macOS 15.7.7, Apple M4 Pro, OpenGL 4.1 (Metal 89.4), .NET SDK 9.0.304, OneScript 2.3.0-dev+12; логическое окно 960×540, render size 1920×1080.

| Профиль | Кадров | Среднее, мс | Среднее FPS | p95, мс | Кубов/кадр | Кадров >100 мс |
|---|---:|---:|---:|---:|---:|---:|
| Исходный мир | 11239 | 2.6694 | 374.62 | 3.9209 | 526 | 0 |
| После 100 успешных изменений | 11917 | 2.5176 | 397.20 | 4.1051 | 540 | 0 |
| Шахматное заполнение | 7107 | 4.2219 | 236.86 | 5.0218 | 1024 | 0 |

Тест производительности пересоздаёт профильные сетки самостоятельно и длится около 105 секунд. Для повторного измерения запустите из корня:

```bash
oscript examples/minecraft/tests/testPerformance.os
```

## Проверки для разработчика

Логические проверки не создают окно и не требуют подключения DLL:

```bash
oscript examples/minecraft/tests/testWorld.os
oscript examples/minecraft/tests/testPlayer.os
oscript examples/minecraft/tests/testRaycast.os
oscript examples/minecraft/tests/testEditing.os
```

Проверка синтаксиса всех OneScript-файлов примера:

```bash
for script in examples/minecraft/app.os examples/minecraft/Классы/*.os examples/minecraft/Модули/*.os examples/minecraft/tests/*.os; do oscript -check "$script" || exit 1; done
```

Shader-проба открывает окно примерно на 3 секунды и проверяет три группы материалов и отсечение:

```bash
oscript examples/minecraft/tests/testLighting.os
```
